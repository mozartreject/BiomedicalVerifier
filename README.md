Research capstone for evidence-backed biomedical claim verification across five phases: representation, retrieval, evidence hierarchy, verification, and explanation.

This initial upload contains **20 Markdown documents and the catalog generator**, documenting 477 local source/configuration files. Application and phase source code, datasets, trained models, environments, and generated inference records are not included in this upload. Local paths refer to the development machine and are not links to files in this repository.

The recorded integrated classifier achieved **67.0% on 300 repeatedly reused development cases**. This is not independent held-out accuracy and does not measure image interpretation or explanation quality.
